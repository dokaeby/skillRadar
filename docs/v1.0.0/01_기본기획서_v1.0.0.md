## 1. 배경 및 목적

AI 코딩 도구(Claude Code, ChatGPT, Gemini CLI) 생태계에서 skill·plugin 저장소가
빠르게 늘어나고 있으나, 플랫폼별 인기 저장소를 한눈에 비교할 수단이 없다.

SkillRadar는 GitHub Search API로 세 플랫폼의 skill/plugin 저장소를 매일 수집한다.
LLM이 생성한 3줄 요약(한글·EN·中文)을 카드 UI로 보여준다. 사용자는
"오늘 어떤 skill/plugin이 인기 있는가"를 즉시 확인할 수 있다.

## 2. 목표

| # | 목표 | 성공 지표 |
|---|---|---|
| G-1 | 플랫폼별 일일 Top 10 자동 수집 | 매일 KST 06:00 스냅샷 3건 생성 |
| G-2 | 다국어 3줄 요약 제공 | LLM 요약 실패 시에도 description 폴백으로 화면 유지 |
| G-3 | 과거 랭킹 조회 | 날짜 선택으로 임의 수집일 스냅샷 조회 |
| G-4 | 비용·rate limit 절감 | content_hash 캐시, GitHub 재시도/backoff |
| G-5 | 신규 트렌딩 알림 | Web Push 구독자에게 플랫폼 Top1 푸시 |

## 3. 범위

### 포함
- GitHub `/search/repositories` 기반 수집 (쿼리 config 분리)
- README 앞 3000자 수집, LLM 3줄 요약(en/zh/ko)
- FastAPI + Jinja2 + Tailwind CDN 카드 UI (반응형, 다크모드)
- APScheduler 일일 스케줄 + 수동 refresh API
- Web Push 알림 (VAPID)
- SQLite/PostgreSQL 이중 지원

### 제외
- 사용자 계정·로그인
- 저장소 상세 분석(코드 품질, 다운로드 수 등)
- 실시간 스트리밍 갱신

## 4. 이해관계자 및 사용 시나리오

- **일반 사용자**: 플랫폼 탭을 전환하며 오늘의 Top 10과 요약을 확인하고 GitHub 원문으로 이동한다.
- **관리자**: `POST /api/admin/refresh`로 즉시 재수집하고, `queries.yaml`로 수집 대상을 조정한다.
- **구독자**: Web Push로 매일 신규 Top1 알림을 받는다.

## 5. 핵심 요구사항 (요약)

1. 수집: `sort=stars&order=desc`, `archived:false fork:false`, 중복 제거, Top 10
2. 저장: repo full_name/URL/description/stars/오늘 증가 star/language/topics/README 앞부분/수집일
3. 요약: JSON 강제(`summary_en`, `summary_zh` + `summary_ko`), 정확히 3줄, 기술 용어 원문 유지, 캐시·재시도·폴백
4. 화면: 탭 3개, 언어 토글, 기준일 표시, 반응형, 다크모드, 날짜 선택
5. API: `GET /api/trending`, `POST /api/admin/refresh` (Bearer 인증)
6. 배포: Render Web Service, uvicorn `0.0.0.0:$PORT` 바인딩
