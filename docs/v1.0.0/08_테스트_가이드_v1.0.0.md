## 3. 수동 검증 체크리스트

- [ ] `uvicorn app.main:create_app --factory --port 8000` 기동 후 `/` 200
- [ ] `python -m app.cli_collect` 실행 → `skillradar.db`에 snapshots/items 생성
- [ ] `/api/trending?platform=claude&lang=ko` 카드 데이터와 일치
- [ ] 날짜 선택 → 과거 스냅샷 조회 (없으면 최신 폴백)
- [ ] `curl -X POST /api/admin/refresh -H "Authorization: Bearer $ADMIN_TOKEN"` → `{"status":"ok"}`
- [ ] `.env`에 `LLM_API_KEY` 설정 후 재수집 → 요약이 description 반복이 아닌 3줄 문장으로 변경

## 4. 커버리지 메모

- GitHubClient의 실제 HTTP 재시도 경로는 MockTransport 미사용(통합 한계) — 로직은 단순 분기라 리스크 낮음
- Web Push 실발송은 VAPID 키 필요 — `push_enabled=False` 경로만 자동 테스트됨
- 스케줄러 발화 자체는 APScheduler 위임 (트리거 설정만 코드 검토)
