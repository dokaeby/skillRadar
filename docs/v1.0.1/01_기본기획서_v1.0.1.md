## 1. 배경 및 목적

AI 코딩 도구(Claude Code, ChatGPT, Gemini CLI) 생태계에서 skill·plugin 저장소가
빠르게 늘어나고 있으나, 플랫폼별 인기 저장소를 한눈에 비교할 수단이 없다.

SkillRadar는 GitHub Search API로 세 플랫폼의 skill/plugin 저장소를 매일 수집하고,
LangGraph 큐레이터 파이프라인이 taxonomy 분류·요약 검증·랭킹 점수·관련 주제를 계산한 뒤
LLM이 생성한 3줄 요약(한글·EN·中文)을 카드 UI로 제공하여
"오늘 어떤 skill/plugin이 인기 있는가"를 즉시 파악할 수 있게 한다.

## 3. 범위

### 포함
- GitHub `/search/repositories` 기반 수집 (쿼리 config 분리)
- LangGraph StateGraph 큐레이터 파이프라인: collect → dedupe_filter → sanitize → classify → summarize → verify → rank → related
- taxonomy 8종 분류(agents/mcp/skills/plugins/devtools/automation/data/other) + 신뢰도
- 요약 충실도 검증(verify) — 실패 시 재요약 최대 2회, 초과 시 `unverified` 표시
- README 앞 3000자 수집, LLM 3줄 요약(en/zh/ko)
- rank_score 기반 정렬(`log10(stars+1)*20 + 요약 ok 보너스 + confidence*5`)
- FastAPI + Jinja2 + TypeScript 바닐라 UI (반응형, 다크모드 기본, PWA)
- 주제 사이드바(최근 30일 관심순), 주제 상세 + 플랫폼 탭, 관련 주제 칩
- 라이선스(SPDX) 배지 표시
- APScheduler 일일 스케줄 + Vercel Cron 수동 refresh + 수동 refresh API
- Web Push 알림 (VAPID)
- 골든 데이터셋 분류 평가 CLI (`backend.eval.run_eval`)
- SQLite/PostgreSQL 이중 지원, Redis JSON 캐시(선택), LangSmith 트레이싱(선택)

### 제외
- 사용자 계정·로그인
- 저장소 상세 분석(코드 품질, 다운로드 수 등)
- 실시간 스트리밍 갱신
- Tavily 연동 (비용 발생으로 도입하지 않음)

## 4. 이해관계자 및 사용 시나리오

- **일반 사용자**: 플랫폼 탭과 주제 사이드바를 오가며 오늘의 Top 10과 요약을 확인하고 GitHub 원문으로 이동한다.
- **관리자**: `POST /api/admin/refresh`(또는 Vercel Cron)로 즉시 재수집하고, `queries.yaml`로 수집 대상을 조정한다.
- **구독자**: Web Push로 매일 신규 Top1 알림을 받는다.
- **개발자**: `run_eval`로 분류 품질을 측정하고, `docs/experiments/`에 결과를 기록한다.

## 5. 핵심 요구사항 (요약)

1. 수집: `sort=stars&order=desc`, `archived:false fork:false`, 중복 제거, star 상위 10개로 LLM 호출 절약
2. 저장: repo full_name/URL/description/stars/오늘 증가 star/language/topics/license(SPDX)/taxonomy+confidence/rank_score/summary_status/README 앞부분/수집일
3. 요약: JSON 강제(`summary_en`, `summary_zh`, `summary_ko`), 정확히 3줄, 기술 용어 원문 유지, 캐시·재시도·폴백, verify 검증
4. 화면: 탭 3개, 언어 토글, 기준일 표시, 주제 탐색, 반응형, 다크모드 기본, 날짜 선택, PWA
5. API: `GET /api/trending`, `/api/dates`, `/api/topics`, `/api/topic-repos`, `/api/related-topics`, `POST /api/admin/refresh` (Bearer 인증)
6. 배포: Vercel serverless (`skill-radar-liart.vercel.app`), Supabase Postgres pooler, Vercel Cron으로 일일 수집
