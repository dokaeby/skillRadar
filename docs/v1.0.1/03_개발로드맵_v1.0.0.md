## 2. 완료된 마일스톤 상세

- **수집 파이프라인**: 쿼리 3개/플랫폼 병합 → `full_name` dedupe → star Top10 → README 3000자 → LLM 요약 → 스냅샷 저장
- **"오늘 증가 star"**: 직전 스냅샷 diff 방식으로 구현 (GitHub API에 일별 증가량 미제공)
- **요약 신뢰성**: 캐시 재사용, JSON 재시도, description 폴백, 항목별 예외 격리
- **UI**: Jinja2 SSR + 바닐라 JS, Pretendard Variable, 플랫폼 포인트 컬러, 스켈레톤 로딩
- **푸시**: VAPID 기반 Web Push, 구독 만료(404/410) 자동 정리
