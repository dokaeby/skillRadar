## 1. 화면 구성

단일 페이지(`/`)로 구성되며, 좌측 주제 사이드바와 우측 카드 그리드로 나뉜다.
탭·토글·날짜·주제 선택으로 전환하며 별도 라우트는 없다.

```
┌──────────────────────────────────────────────────────────┐
│ Header (sticky, glass)                                   │
│  [SR 로고 SkillRadar]   [한글|EN|中文] [테마] [🔔 알림]   │
│  [Claude|ChatGPT|Gemini]            기준일 [2026-11-18▾] │
├──────────────┬───────────────────────────────────────────┤
│ 관심 주제     │  (트렌딩 모드)                             │
│ (최근 30일)  │  Card Grid (1열/2열/3열 반응형)              │
│  #topic 12   │   ┌─────────┐ ┌─────────┐ ┌─────────┐      │
│  #topic 8    │   │ #1 랭크 │ │ #2 랭크 │ │ #3 랭크 │      │
│  #topic 5    │   │ repo명↗ │ │         │ │         │      │
│  (가로 스크롤│   │ [MIT][JS│ │         │ │         │      │
```

## 2. 사용자 흐름

### 2.1 랭킹 조회 (트렌딩)
1. 페이지 진입 → `loadTopics()`로 사이드바 채우고, 기본 `claude` 탭·최신 수집일·`ko` 요약 로드
2. 플랫폼 탭 클릭 → `/api/dates`로 해당 플랫폼 수집일 목록 갱신 → 최신 날짜로 `/api/trending` 재조회
3. 날짜 선택 → 해당 `collected_date` 스냅샷 조회 (없으면 최신으로 폴백, 응답 `date`가 실제 기준일)
4. 언어 토글 → 동일 날짜 데이터의 다른 언어 요약으로 재렌더링 (재수집 없음)

### 2.2 주제 탐색
1. 사이드바 주제 클릭 → `/api/topic-repos?topic=...&platform=all&lang=ko&limit=10` 조회
   - 그리드는 `rank_score`→`stars` 순으로 정렬된 결과를 표시 (rank는 1부터 재부여)
2. 주제 상세 헤더에 `최근 30일 N개 저장소` 표시, 플랫폼 탭(전체/Claude/ChatGPT/Gemini)으로 필터
3. `/api/related-topics`로 관련 주제 칩 표시 — 클릭 시 해당 주제로 전환
4. "← 트렌딩으로 돌아가기" → 사이드바 선택 해제, 트렌딩 그리드 복귀

### 2.3 Web Push 구독 (PWA)
1. 헤더 "알림 받기" 클릭 → Service Worker(`/sw.js`) 등록 → `Notification.requestPermission`
2. 허용 시 `pushManager.subscribe`(VAPID 공개키, `/api/push/vapid-key`) → `POST /api/push/subscribe`
3. 구독 중이면 버튼 상태 변경, 재클릭 시 unsubscribe
4. 매일 수집 완료 후 플랫폼별 Top1 알림 수신 → 클릭 시 `/?platform=<p>` 이동
5. `/manifest.json` + 아이콘으로 홈 화면 추가 가능 (iOS는 Safari "홈 화면에 추가" 필요)

### 2.4 관리자 수동 수집
- `POST /api/admin/refresh` (Bearer `ADMIN_TOKEN`) → 즉시 전체 플랫폼 수집 + 푸시
- 배포 환경에서는 `vercel.json` Cron이 매일 `/api/admin/refresh`를 호출

## 3. UI 정책

| 항목 | 정책 |
|---|---|
| 카드 순위 | 1~10 배지, star 내림차순 정렬 유지 (주제 모드는 rank_score 순) |
| 라이선스 | SPDX id를 amber 배지로 표시, `licenseShort()`로 축약 (BSD-3-Clause→BSD-3 등) |
| star 표시 | 1000 이상 `k` 단위 축약 (예: 305.5k) |
| 오늘 증가량 | `+N`(녹색)/`±0`(회색)/데이터 없음 `—` |
| 요약 표시 | 선택 언어 3줄, `line-clamp`로 3개 `<li>` 표시 |
| GitHub 링크 | repo명과 "GitHub에서 보기 ↗" 버튼 모두 `target=_blank rel=noopener` |
| 로딩 | 스켈레톤 카드 6개 + 사이드바 스켈레톤, 에러 시 메시지 행 |
| 빈 상태 | "아직 수집된 데이터가 없습니다" + 수집 주기 안내 |
| 테마 | 기본 다크(`html class="dark"`), 토글 시 localStorage `sr-theme` 저장 |
| 사이드바 | 데스크톱 sticky 세로 목록, 모바일 가로 스크롤. `/api/topics` 상위 50개, 각 항목에 count 배지 |
| 관련 주제 | 칩 최대 8개 표시(원본 상위 10개 중 자기 자신 제외), 클릭 시 주제 전환 |
| 폰트 | Pretendard Variable (CDN), 시스템 폰트 폴백 |
| 반응형 | `grid-cols-1 md:grid-cols-2 xl:grid-cols-3`, 사이드바 `lg:` 분기 |

## 4. 접근성·품질

- 시맨틱 태그: `header`, `nav`, `aside`, `main`, `article`, `footer`
- 모든 외부 링크 `rel="noopener"`, XSS는 `escapeHtml`로 이스케이프
- 다크모드 대비: slate 팔레트 + 플랫폼 포인트 컬러(claude `#d97757`, chatgpt `#10a37f`, gemini `#4285f4`)
- `prefers-reduced-motion` 미대응(전환 애니메이션은 경미)

## 5. 알려진 제약

- Tailwind CDN은 프로덕션 경고 발생 — 기능상 문제없으나 번들 도입 시 교체 권장
- 첫 수집일은 `stars_today`가 `—` (비교 대상 없음)
- LLM 미설정 시 요약이 description 폴백(동일 문구 3줄)으로 표시되고 `summary_status='failed'`
- verify까지 실패한 항목은 `summary_status='unverified'` — 현재 UI는 이 상태를 별도 표시하지 않음
- taxonomy/rank_score는 API 응답에 포함되지만 카드 UI에는 아직 표시하지 않음
