## 3. 수동 검증 체크리스트

- [ ] `npm install && npm run build` 후 `uvicorn backend.main:create_app --factory --port 8000` 기동 → `/` 200
- [ ] `python -m backend.cli_collect` 실행 → `skillradar.db`에 snapshots/items 생성
- [ ] `/api/trending?platform=claude&lang=ko` 카드 데이터와 일치
- [ ] `/api/topics` → 주제 클릭 흐름(`/api/topic-repos`, `/api/related-topics`) 확인
- [ ] 날짜 선택 → 과거 스냅샷 조회 (없으면 최신 폴백)
- [ ] `curl -X POST /api/admin/refresh -H "Authorization: Bearer $ADMIN_TOKEN"` → `{"status":"ok"}`
- [ ] `python -m backend.eval.run_eval` → `docs/experiments/{날짜}-eval-baseline.md` 생성 (`LLM_API_KEY` 필요)
- [ ] `npx pyright` → 0 errors

## 4. 커버리지 메모

- GitHubClient의 실제 HTTP 재시도 경로는 MockTransport 미사용(통합 한계) — 로직은 단순 분기라 리스크 낮음
- Web Push 실발송은 VAPID 키 필요 — `push_enabled=False` 경로만 자동 테스트됨
- 스케줄러 발화 자체는 APScheduler 위임 (트리거 설정만 코드 검토)
- verify 노드의 재요약 루프는 llm_tasks 단위 테스트 + collector 통합 테스트로 간접 검증
